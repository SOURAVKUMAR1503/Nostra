# 🛍️ NOSTRA - E-Commerce Website

Nostra is a responsive fashion e-commerce website built using HTML, CSS, and JavaScript. It provides a clean and simple shopping interface where users can explore products, search for products, filter products by category, and contact the store.

## 📌 Project Overview

Nostra is a frontend e-commerce website created as part of a web development project.

The website focuses on creating a clean, responsive, and user-friendly shopping experience. It contains multiple pages and uses JavaScript to add interactive features such as product searching, category filtering, and closing promotional offers.

The project is designed using basic frontend technologies without any backend or database.

## 📄 Pages

### 🏠 Home Page

The Home page introduces the Nostra brand and provides an overview of the products and offers.

It includes:

- Navigation bar
- Promotional offer section
- Hero section
- Brand section
- New arrivals
- Most wanted products
- Limited-time offer
- Newsletter section
- Footer

---

### 🛍️ Collections Page

The Collections page displays the available products in a responsive grid layout.

It includes:

- Product images
- Product names
- Product prices
- Product categories
- Search functionality
- Category filter buttons

### Available Categories

- All
- Men
- Women
- Shoes
- Accessories

Users can search for products by typing the product name in the search box.

---

### 📞 Contact Us Page

The Contact Us page allows users to find basic store information and send a message.

It includes:

- Contact information
- Email
- Phone number
- Address
- Name field
- Email field
- Subject field
- Message field
- Send Message button

---

## 🔍 Search Functionality

The Collections page includes a JavaScript-based search feature.

Users can enter a product name in the search box and the products are filtered automatically based on the entered text.
